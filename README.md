## 🛠️ Guia de Atualização Rápida
1. Clique no botão de edição (lápis) no GitHub.
2. Adicione os dados do seu cliente preenchendo as lacunas `[ ]`.
3. Quando fechar a venda, você pode recortar a linha do cliente e colá-la na coluna de baixo (**Serviços Agendados** ou **Pós-Venda**).
4. Substitua o `[ ]` por `[x]` para dar o "check" de tarefa cumprida!
